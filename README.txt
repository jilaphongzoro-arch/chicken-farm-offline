ฟาร์มไก่ — ชุดเว็บแอปติดตั้งบน Android (PWA)
ไฟล์ในชุด:
- index.html: แอปจัดการไก่
- manifest.json: ชื่อและไอคอนแอป
- sw.js: แคชไฟล์เพื่อใช้งานออฟไลน์
- icons/: ไอคอน 192 และ 512 px

สำคัญ:
1) ต้องนำไฟล์ทั้งหมดไปเผยแพร่บนเว็บ HTTPS ก่อน จึงจะติดตั้งเป็น PWA ได้
2) เปิด URL ของเว็บที่เผยแพร่แล้วด้วย Chrome บน Android และเลือก ⋮ > ติดตั้งแอป หรือ เพิ่มไปยังหน้าจอหลัก
3) เปิดแอปหนึ่งครั้งขณะออนไลน์เพื่อให้ไฟล์ถูกแคช จากนั้นทดสอบโหมดเครื่องบิน
4) ข้อมูลบันทึกในพื้นที่ของเบราว์เซอร์/แอปเครื่องนั้น โปรดส่งออก JSON สำรองเป็นประจำ
5) ชุดนี้เป็น PWA ไม่ใช่ APK ดั้งเดิม
